# Hooks and shapes

The first line is read alone, before "see more" (roughly 140 characters on mobile, more on desktop; it varies by device). It has to make the next line worth reading. Offer three hooks from **different** patterns, each true for this idea.

## Hook patterns

| Pattern | Shape | Use when | Ruined by |
|---|---|---|---|
| Before and after | "X used to take {time}. Now it takes {time}." | a measurable change the user made | a vague change ("much faster") |
| The cost | "{Mistake} cost us {number}." | the user paid for a lesson | a cost the user can't name publicly |
| The contrarian | "{Common advice} is wrong for {specific group}." | a position from the voice profile | contrarian for its own sake; no reason given |
| The scene | One line of something that happened, mid-action | a story with a person and a moment | backstory before the moment |
| The specific number | "{Number} {things} in {time}: what changed." | the number is the user's own | rounded or borrowed numbers |
| The question only you could ask | a question that names the situation | a genuine open problem | "Thoughts?" or "Have you ever...?" |
| The decision | "We stopped doing {X}." | a choice with a reason and a result | no result yet |
| The confession | "I was wrong about {X}." | a real change of mind | false humility |
| The list with a filter | "{N} {things} I'd keep if I had to cut the rest." | practical teaching | a list of tools anyone could write |
| The teardown | "What {named public example} got right about {X}." | analysing public work with credit | punching down, or claims about private details |
| The direct value | "The {thing} we use for {job}, given away below." | a template or checklist the user owns | gating it behind "comment to get it" |
| The quote | a sentence someone actually said, with permission | a customer or colleague line that captures the idea | invented or paraphrased quotes |

If a hook would work with anyone else's name on it, it's too generic. Numbers beat adjectives. No question mark in line 1 unless only this user could ask it.

## Body shapes

- **Proof:** what happened → the number → why it worked → what the reader can take.
- **Opinion:** the claim → the strongest objection, stated fairly → why the user still holds it → where it doesn't apply.
- **Teach:** the problem → steps (3-5, each one line) → the result to expect.
- **Story:** scene → tension → what was decided → the cost or payoff → the lesson in one line.
- **Offer:** who it's for → the problem → what the user does → one proof → how to start. Said plainly, no apology.

## Articles and newsletters

Headline under 100 characters that states the payoff; a standfirst of one or two sentences; subheads every 300-400 words; one idea per section; sources linked inline. Draft with `article-writing`.

## Document (carousel) posts

Cover: the payoff in under ten words. One idea per slide, under about 25 words each, large type. Last slide: what to do next and who wrote it. The post text says why the document is worth opening and doesn't repeat the slides.
