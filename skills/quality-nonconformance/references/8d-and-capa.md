# 8D steps and CAPA record checklist

Read this when running an 8D, writing a CAPA procedure, or preparing CAPA records for an audit.

## 8D (Eight Disciplines)

| Step | Purpose | Output |
|---|---|---|
| D0 Plan | decide 8D is warranted, emergency response | symptom, emergency actions |
| D1 Team | cross-functional team with process knowledge and a champion | names, roles |
| D2 Describe the problem | what, where, when, how many, is/is-not | problem statement with data |
| D3 Interim containment | protect the customer now | containment actions, verification |
| D4 Root causes | occurrence and escape causes, verified | cause statements with evidence |
| D5 Choose corrective actions | actions proven to remove each cause | selected actions, verification plan |
| D6 Implement and validate | put actions in place, remove containment when proven | results data |
| D7 Prevent recurrence | update systems: PFMEA, control plan, procedures, similar products | updated documents, lessons learned |
| D8 Recognise the team | close formally | closure approval |

Customers often impose their own 8D form and response times (for example containment within 24 hours, root cause within days). Use the customer's form and deadlines when they exist.

## CAPA record checklist

- Source (NCR, complaint, audit, trend, supplier) with link.
- Problem statement with data and scope.
- Investigation proportionate to risk, with root cause evidence.
- Actions, owners, due dates, and verification that actions do not harm product safety or conformity.
- Documents changed, with revision.
- Training done, with records.
- Effectiveness criteria set at opening, the check, the data, the result.
- Approvals and dates, with signatures meeting the site's electronic records rules.
- Link to management review and trend reports.

Common audit findings: CAPAs closed without effectiveness evidence, root cause stated as "human error", overdue CAPAs with no escalation, preventive actions missing, and trend data not feeding the CAPA system.
